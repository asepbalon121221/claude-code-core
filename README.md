# 💻 Claude Leaks

On March 31, 2026, Anthropic accidentally leaked over 512,000 lines of unobfuscated TypeScript source code for their terminal tool, Claude Code, which is a command-line interface for interacting with the Claude AI model. This repository contains the complete leaked code, providing insights into the architecture, tools, and commands used by the agent, available for educational and research purposes.

<img src="./assets/demo.gif" />

# ✨ Main Features

- **Full leaked code**: Complete TypeScript implementation of Claude Code.
- **Original architecture**: Original structure and design of the leaked code.
- **Tool integration**: Includes all tools and commands used by the agent.

# ✅ Prerequisites

- Interest in exploring the leaked source code of Claude Code.
- Basic understanding of TypeScript and Node.js programming.
- Familiarity with command-line tools and terminal applications.
